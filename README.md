# DebtPlan — «Долговой план»

Локальный калькулятор порядка погашения долгов. Пользователь вводит список
кредитных продуктов и сумму, которую он может направлять на погашение каждый
месяц. Приложение считает переплату, срок и дату полного погашения, сравнивает
несколько стратегий и строит помесячный график платежей.

Приложение работает полностью в браузере. Данные не отправляются на сервер и
хранятся только в `localStorage`.

## Стек

- React 19
- Vite 8
- JavaScript (ES modules)

## Команды

Установка зависимостей:

```bash
npm install
```

Запуск dev-сервера (http://localhost:5173):

```bash
npm run dev
```

Сборка продакшн-версии в папку `dist/`:

```bash
npm run build
```

Предпросмотр собранной версии:

```bash
npm run preview
```

## Допущения расчёта

- Проценты начисляются раз в месяц: месячная ставка = годовая ставка / 12.
- При закрытии долга его минимальный платёж добавляется к свободной сумме.
- Комиссии, страховки и льготные периоды не учитываются.
- Поддерживается только одна валюта — российский рубль.
