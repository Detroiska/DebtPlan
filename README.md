# DebtPlan — «Долговой план»

Локальный калькулятор порядка погашения долгов. Пользователь вводит список
кредитных продуктов и сумму, которую он может направлять на погашение каждый
месяц. Приложение считает переплату, срок и дату полного погашения, автоматически
выбирает оптимальную стратегию, позволяет сравнить стратегии между собой
(включая заданный пользователем порядок) и строит помесячный график платежей.

Приложение работает полностью в браузере. Данные не отправляются на сервер и
хранятся только в `localStorage`.

## Стек

- React 19
- Vite 8
- JavaScript (ES modules)
- Vitest (юнит-тесты расчётного модуля)

## Команды

Установка зависимостей:

```bash
npm install
```

Запуск dev-сервера (http://localhost:5173):

```bash
npm run dev
```

Сборка продакшн-версии в папку `dist/`:

```bash
npm run build
```

Предпросмотр собранной версии:

```bash
npm run preview
```

Запуск юнит-тестов расчётного модуля (Vitest):

```bash
npm test
```

## Допущения расчёта

- Проценты начисляются раз в месяц до платежа: месячная ставка = годовая / 12.
- Минимальные платежи берутся из договора; после закрытия долга его минимум
  автоматически достаётся следующему в порядке погашения.
- Досрочные платежи распределяются по порядку стратегии; при заданной
  безрисковой ставке долги дешевле накоплений гасятся только минимумами.
- Оптимальная стратегия помечается автоматически: минимум переплаты,
  при равенстве — кратчайший срок.
- Комиссии, страховки и штрафы не учитываются; поддерживается только рубль.

Расчёт носит справочный характер и не является финансовой рекомендацией.
